2. 何が最も成果に寄与したか
最大の成功要因

「A→B→C」の工程分離です。

A：読者体験（感情）

B：構造（役割）

C：方法論（再現性）

これにより、

「面白い／面白くない」

「好き／嫌い」

といった主観評価に引きずられず、
常になぜそう感じるのか
を言語化できていました。

これは個人制作で最も失敗しやすい点を回避しています。

途中であなたが気づいた、

という問題は、最終的にほぼ解消されました。

解消された理由

呼称

行動原理

4. AI生成との相性についての結論

今回の工程は、
AIを「作家」にしなかった点が非常に重要です。

AIは：

設計を言語化する補助

「AIに書かせた」ではなく
