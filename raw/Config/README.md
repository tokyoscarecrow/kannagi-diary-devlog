# Config（一次資料）

このディレクトリには、
『かんなぎダイアリー』制作において
実際に使用された Narrative Composer Config を収録します。

## GLOBAL CONFIGについて
`/config/GLOBAL_CONFIG.yaml` は、このプロジェクトの最上位ガバナンスファイルです。

このファイルでは、以下の項目が定義されています。
- 不変ルール
- レイヤーの優先順位
- 構造変更プロトコル
- シーンカードのガバナンス
- アンチドリフト状態管理

下位レベルのすべての設定、シーンカード、​​およびプローズ出力は、このファイルに従う必要があります。
競合が発生した場合は、黙って解決するのではなく、明示的に報告する必要があります。

## 設計原理レイヤーについて（PROJECT MASTER CONTEXT）
本リポジトリでは、Scene Card・Tension Curve・Reviewといった  
制作工程の前提として、

> **作品の判断基準そのものを定義するレイヤー**
を導入しています。それが `PROJECT_MASTER_CONTEXT.yaml` です。

### なぜ必要か
本プロジェクトは、

- 長期的な制作
- AIによる生成
- 多数の判断・修正の積み重ね

によって進行します。
このとき問題になるのは、

- 初期の設計意図が徐々に失われる
- 局所的な改善が全体構造を壊す
- 判断基準が場当たり的になる

という現象です。これを防ぐために、

> **「判断基準そのもの」を固定する必要があります**

### 何を定義するか
`PROJECT_MASTER_CONTEXT.yaml` では主に以下を定義します：

- テーマ原理（何を描く作品か）
- 世界論理（どう成立している世界か）
- 物語駆動原理（何が物語を動かすか）
- トーン（どのような質感の作品か）
- 禁止事項（何をしてはいけないか）

### GLOBAL_CONFIG との関係

本プロジェクトでは、以下の二層構造を採用しています：

- `GLOBAL_CONFIG.yaml`  
  → 制作プロセスの統治（どう作るか）

- `PROJECT_MASTER_CONTEXT.yaml`  
  → 作品の原理定義（何を作るか）

### 実務上の使い方

制作時には：

- 新しい構造案やScene案が
- このContextに整合しているか

を必ず確認します。
不整合がある場合：

- 自動修正は行わず
- 問題として扱います

## addressing_rules.yaml について  
使用段階：連載第2段階後半以降  
目的：  
キャラクター同士の呼称・敬称・心理距離を独立管理し、会話生成時の揺らぎを抑制する。

特徴：

・キャラクター間の呼び方を固定  
・心理距離の変化をイベント単位で管理  
・本体Configから分離し、関係表現レイヤーとして運用

備考：  
呼称変化は特定イベント後にのみ切り替える。

## config_v2.5.yml について 
- 使用段階：連載第2段階後半（EP02_SC04作成時点）
- 目的：  
　口調の設定を追加。セリフ生成時の揺らぎを抑制しキャラクターの識別性と一貫性を向上
- 特徴：CHARACTER_LAYER v1.1
  - 全キャラクターに口調仕様（speech_specification）を追加
  - 隼太／みずは／真魚／住吉／明神の発話スタイルを明文化
  - キャラクター間の口調差異を構造的に固定
- 備考：  
  - 本更新は非破壊的変更（既存設定には影響なし）
　- 主に本文生成フェーズでの品質安定を目的とする
 
## config_v2.4.yml について 
- 使用段階：連載第2段階後半（EP02構造確定時点）  
- 目的：  
　EP02設計で確定したキャラクター動機と長期アークを正式反映し、人物駆動構造を強化する。
- 特徴：
  - 氷川真魚の動機を「復讐型」から「救済型」へ刷新  
　- 制度破壊志向から制度再定義へ至る長期アークを明文化  
　- 隼太との関係を「利用」から「対等」へ固定  
  - 真魚の敬語仕様を制作ルールとして明確化  
  - 魔法使用の心理的コストをHBCに追加  
　- EP02固有構造を本体Configから分離
- 備考：  
  - キャラクター構造に関わる重要更新を含むバージョン。

## config_v2.3.yml について
- 使用段階：連載第2段階（EP02設計時点）
- 目的：世界観・キャラクター・監視ルールを固定した上で、
  AI生成の揺らぎを抑制。さらに本文生成時の文章表現を改善する。
- 特徴：
  - 人間の行動を表現する際により自然にものにする
  - 新レイヤー　human_behavior_constraints を追加
  - EP02の進行にともない、逐次改訂する予定

## config_v2.2_working.yml について
- 使用段階：連載初期（EP01設計時点）
- 目的：世界観・キャラクター・監視ルールを固定した上で、
        AI生成の揺らぎを抑制する
- 特徴：
  - 世界設定・政府機構・倫理構造を詳細に定義
  - キャラクターごとに speech_style / change_arc を明示
  - 評価項目（evaluation）を Config 内に内包
  - v2.0、2.1は完成本文の生成には使用しなかっため省略するが、v2.2の内容はすべて含まれている。
